# Archive

Older configurations kept for reference. They are **not maintained** and are not tested in CI.

| File | Description |
| --- | --- |
| `sysmonconfig.xml` | The first config in this repo, based on [SwiftOnSecurity/sysmon-config](https://github.com/SwiftOnSecurity/sysmon-config) version 51 (2017). Replaced by [`sysmonv9.xml`](../sysmonv9.xml). |

To bring one up to date, import it into the [config builder](https://0xanalyst.github.io/Sysmon/), which upgrades older schemas and flags problems.
